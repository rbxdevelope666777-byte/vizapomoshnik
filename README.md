# 🛂 ВизаПомощник — сайт с ИИ для помощи в оформлении визы

Веб-приложение на Node.js + Express, использующее OpenAI API (ChatGPT, по умолчанию `gpt-5.4-mini`).

## Возможности
1. **💬 ИИ-консультант** — чат со стримингом ответов: тип визы, документы, порядок подачи, сроки.
2. **📋 Чек-лист документов** — по гражданству, стране назначения и цели поездки генерирует
   персональный список документов (структурированный JSON → интерактивные чекбоксы),
   шаги, сроки, сборы и официальные источники.
3. **✉️ Сопроводительное письмо** — генерация cover letter в консульство на нужном языке.

## Запуск
```bash
npm install
export OPENAI_API_KEY=sk-...
npm start
```
Откройте http://localhost:3000

На Windows проще всего дважды щёлкнуть `ЗАПУСК.bat`.

Переменные окружения: `OPENAI_API_KEY`, `PORT` (по умолчанию 3000), `OPENAI_MODEL` (например `gpt-5.5`, `gpt-4.1-mini`).

## Структура
```
server.js          — API: /api/chat, /api/checklist, /api/letter
public/index.html  — интерфейс
public/app.js      — логика фронтенда (стриминг SSE)
public/style.css   — стили (светлая/тёмная тема, мобильная вёрстка)
```

## Технические детали
- Чек-лист генерируется через Structured Outputs (строгая JSON-схема).
- Ассистент не помогает с подделкой документов и всегда напоминает проверять требования
  на официальных сайтах.

## Идеи для развития
- Авторизация и сохранение истории/чек-листов (БД)
- Загрузка сканов документов (PDF/фото) для проверки ИИ
- Напоминания о сроках подачи и записи в визовый центр
- Помощь в заполнении конкретных анкет (DS-160, шенгенская анкета)
